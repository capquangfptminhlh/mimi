# Lumi Pet Shop — Website OS replacement

Production replacement is developed on branch `replace/website-os-v1` under governance from `capquangfptminhlh/seo-web`.

Public launch scope: homepage, Spa, Grooming, Pet Hotel, Pet Shop, pricing, booking, contact, about and FAQ.

Booking integrates with the existing Worker API when `assets/api-config.js` has a `baseUrl`; otherwise the browser creates a local request code and directs the customer to confirm with Lumi.

Release remains HOLD until deployed desktop/mobile runtime and approved-demo comparison pass.
